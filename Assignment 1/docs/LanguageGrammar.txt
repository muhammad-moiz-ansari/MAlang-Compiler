===========================================================
               MALANG LANGUAGE SPECIFICATION
            (Manual Scanner Implementation Logic)
===========================================================

1. CHARACTER SET
   The scanner accepts ONLY the following characters:
   - Letters: a-z, A-Z
   - Digits:  0-9
   - Symbols: # _ , : ; ( ) [ ] { } . + -
   - Whitespace: \n, \t, \r, Space

   *NOTE: Quotes (' and ") and Operators (* / = ! < >) are NOT 
    in the allowed alphabet and will trigger "Invalid Character" errors.*

2. WHITESPACE
   Recognized as valid tokens:
   - Space             (' ')
   - Horizontal Tab    ('\t')
   - Newline           ('\n')
   - Carriage Return   ('\r')

3. COMMENTS
   - Single-line ONLY: Starts with '#' (implied by State 3).
   - Multi-line comments are NOT supported in this implementation.

4. KEYWORDS / BOOLEANS
   The scanner contains specific transition logic for:
   - true
   - false

5. IDENTIFIERS
   - Supported Pattern: Starts with a letter, followed by letters/digits.
   - CONSTRAINT: Maximum length is strictly 31 characters.
     (Code: if idcons >= 32 -> Error "Maximum 31 characters allowed")

6. LITERALS

   A. Integer Literals
      - Digits only.
      - Includes signed integers (implied by '+' and '-' in alphabet).

   B. Floating-Point Literals
      - Numbers containing a decimal point and optional exponent ('e'/'E').
      - CONSTRAINT: Maximum 6 digits allowed strictly after the decimal point.
      - (Code: if floatcons >= 7 -> Error "Maximum 6 characters allowed...")

   C. String & Char Literals
      - NOT SUPPORTED. (Quotes are missing from the 'alphabets' array).

7. PUNCTUATORS
   The following symbols are recognized as distinct tokens:
   - Round Brackets:  ( )
   - Curly Braces:    { }
   - Square Brackets: [ ]
   - Separators:      ,  ;  :

8. OPERATORS
   - General arithmetic/logic operators are NOT tokenized.
   - '+' and '-' are present in the alphabet but appear to be used 
     primarily for signed number literals in this specific logic.
